# Академия — платформа для студентов курса

Личный кабинет для небольшой группы: домашки с фото и видео, разбор с голосом и пометками на фото, доска с постами и промптами, видео-уроки, карта прогресса, опросы после модулей, сводка «кто отстаёт» и уведомления в Telegram.

## Что умеет

**Студент**
- Главная: прогресс, ближайшие дедлайны, задания на доработку, новые посты
- Доска: заметки, промпты с кнопкой «Скопировать», объявления; новое выделено маркером
- Видео-уроки (YouTube/Vimeo/Loom/Google Drive/Rutube/mp4) с отметкой «пройдено»
- Домашки: загрузка фото и видео с телефона (фото сжимаются в браузере), история попыток и разборов
- Карта прогресса по модулям, опрос «оценка 1–10 + что улучшить» после модуля
- Подключение Telegram в профиле

**Преподаватель (/admin)**
- Сводка «кто отстаёт»: последний вход, просрочки, доработки, непрочитанные посты, низкие оценки
- Очередь проверки: статусы «Отправлено → На проверке → Доработать → Принято»
- Разбор: комментарий, голосовое или видео прямо из браузера, пометки и номерные метки на фото
- Доска: посты всем или выбранным студентам, видно, кто прочитал
- Курс: модули, уроки, задания с дедлайнами
- Студенты: создание аккаунтов, сброс пароля, отключение доступа
- Telegram: уведомления о новых домашках, низких оценках и утренняя сводка

**Telegram-уведомления**
- студенту: разбор домашки, новый пост, новое задание или урок, опрос, напоминание за день до дедлайна
- преподавателю: новая домашка или доработка, оценка модуля, сводка каждый день в 9:00 (Алматы)

## Стек (всё на бесплатных тарифах)

- Next.js 16 (App Router, Server Actions) + Tailwind CSS 4
- Postgres: Neon (прод), PGlite (локально, без установки)
- Drizzle ORM, миграции в `drizzle/`
- Файлы: Vercel Blob (загрузка из браузера напрямую)
- Хостинг и ежедневный cron: Vercel

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | строка подключения Postgres (Neon). Локально `pglite:./.data/pglite` |
| `SESSION_SECRET` | секрет для подписи сессий (32+ символа) |
| `CRON_SECRET` | секрет для `/api/cron/daily` (Vercel Cron передаёт его сам) |
| `BLOB_READ_WRITE_TOKEN` | выдаётся Vercel при подключении Blob-хранилища |
| `TELEGRAM_BOT_TOKEN` | токен бота из @BotFather (можно вместо этого вставить в админке) |
| `SEED_USERS` | JSON со стартовыми аккаунтами — используется, только если пользователей ещё нет |
| `NEXT_PUBLIC_APP_NAME` | название платформы (по умолчанию «Академия») |
| `NEXT_PUBLIC_STORAGE=local` | только для локальной разработки: файлы в `.data/uploads` |

## Деплой на Vercel (бесплатно)

1. **Import** репозитория в Vercel (Add New → Project). Фреймворк определится сам (Next.js). В Environment Variables сразу добавь:
   - `SESSION_SECRET` — длинная случайная строка
   - `CRON_SECRET` — другая случайная строка
   - `TELEGRAM_BOT_TOKEN` — токен бота
   - `SEED_USERS` — JSON со стартовыми аккаунтами
2. После создания проекта: **Storage → Create Database → Neon** (регион Frankfurt, план Free) → Connect к проекту. Vercel сам добавит `DATABASE_URL`.
3. **Storage → Create → Blob** (регион Frankfurt) → Connect к проекту. Добавится `BLOB_READ_WRITE_TOKEN`.
4. **Deployments → ⋯ → Redeploy.** Во время сборки создадутся таблицы и аккаунты из `SEED_USERS`, подключится вебхук Telegram.
5. Проверка: `https://<твой-домен>/api/health` должен вернуть `{"ok":true,"db":"ok","storage":"blob"}`.

Функции работают в регионе Frankfurt (`vercel.json`) — ближе всего к Казахстану; база и хранилище должны быть там же.

## Локальный запуск

```bash
npm install
cp .env.example .env.local
SEED_USERS='[{"role":"admin","name":"Admin","login":"admin","password":"admin-pass-123"}]' npm run db:migrate
npm run dev
```

## Тесты

Сквозной тест проходит все сценарии студента и преподавателя в настоящем браузере (фейковый Telegram, локальная база):

```bash
npm run build && npm run test:e2e
```

Скриншоты сохраняются в `tests/artifacts/`.

## Изменение схемы БД

Поменяй `src/lib/db/schema.ts`, затем `npm run db:generate` — миграция применится автоматически при следующем деплое.
